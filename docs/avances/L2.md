# L2 · Composicion: encadenar sin equivocarse

> Cierre: [L2-cierre.md](../arquitectura/loops/L2-cierre.md) ·
> Indice: [INDICE.md](../arquitectura/loops/INDICE.md)

**Que puedes hacer ahora que antes no podias.** Puedes encadenar herramientas y el orden nunca se equivoca. Si dos se necesitan entre si, el sistema te dice cuales son, en vez de fallar en silencio.

**Que se volvio mas tuyo o mas seguro.** Si una herramienta usa otra, solo lo hace una vez. No hay doble cobro.

**Lo que nos equivocamos en esta ronda.** El error que veias no era el error: el orden de las comprobaciones hacia que un ciclo se reportara como «este sumidero no es terminal», cuando el problema real era un ciclo. Y el cierre anterior habia dejado un archivo 53 bytes por encima del limite, mientras el numero que lo reportaba decia que todo estaba bien. Se tapo recortando la prosa en vez de partir el archivo por donde tenia una sola responsabilidad.

**Lo que quedo abierto.** La herramienta de busqueda declara que puede leer la red y no puede: falta el transporte. El caso canonico existe para que ese hueco se vea en cada corrida y no se acumule en un documento que nadie vuelve a leer.
