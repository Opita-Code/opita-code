# L1 · Runtime: la caja de cada herramienta

> Cierre: [L1-hallazgos-gate.md](../arquitectura/loops/L1-hallazgos-gate.md) ·
> Indice: [INDICE.md](../arquitectura/loops/INDICE.md)

**Que puedes hacer ahora que antes no podias.** Cada herramienta vive en una caja: solo puede hacer lo que su caja le concede, y se comprueba antes de dejarla correr. Si intenta salirse, la ejecucion falla aunque la herramienta hubiera funcionado.

**Que se volvio mas tuyo o mas seguro.** Tu rastro de auditoria ya no se puede editar. Antes las entradas de la bitacora eran mutables, y un rastro que se puede editar no es un rastro.

**Lo que nos equivocamos en esta ronda.** El constructor de WASM escribia un byte de mas. Y un test estaba mal planteado: tomaba env.memory por el disco, y no lo es.

**Lo que quedo abierto.** Los tres niveles de aislamiento existen como politica verificada, no como ejecucion real: no hay Pyodide, ni WebContainers, ni Firecracker conectados. Por eso no se publica que el sistema ejecuta con red.
